# 推荐评测说明

## 数据集

`synthetic-redacted-v2` 包含 15 个脱敏演示岗位和 15 类候选人画像。每类画像设置 4 个受控变体，分别测试完整技能描述、部分技能缺失、无关技能噪声和不同文本格式，共 60 条样例。相关岗位由人工按岗位方向和技能要求标注。

该数据集用于回归测试，不包含真实求职者和招聘决策。四个变体来自同一基础画像，因此不能将 60 条样例理解为 60 名独立候选人，也不能将指标解释为真实录用效果。

## 运行方式

```bash
cd ai-service
PYTHONPATH=. python evals/run.py
```

脚本会对每条画像实时运行当前确定性基线，取前 5 个岗位，再计算宏平均 Recall@5、Precision@5 和 MRR。评测不再读取预先写好的排序结果。

## 当前结果

| 模式 | 样例数 | Recall@5 | Precision@5 | MRR |
| --- | ---: | ---: | ---: | ---: |
| 可解释基线 | 60 | 82.78% | 31.33% | 91.39% |

Precision@5 较低的原因之一是每类画像的人工相关岗位通常少于 5 个，而系统固定返回 5 个结果。该指标适合版本间对比，不应单独作为产品效果结论。

## 后续评测

- 配置真实 Embedding 和大模型服务后，分别记录 `BASELINE`、`EMBEDDING`、`LLM_RERANK` 三种模式的结果与延迟。
- 扩充独立人工编写的画像和岗位描述，避免同一基础画像的变体占比过高。
- 增加证据一致性、技能幻觉率和降级成功率，验证模型解释是否严格来自简历事实。
- 真正上线前使用获得授权的脱敏数据，并由多人复核相关性标签。
